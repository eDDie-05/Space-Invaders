# Space Invaders Game

A classic **Space Invaders-style arcade game** developed as a programming project. The player controls a spaceship, shoots incoming enemies, and tries to achieve the highest possible score.

## Features

* Player-controlled spaceship
* Multiple enemy formations
* Shooting system
* Enemy movement
* Collision detection
* Score tracking
* Lives system
* Increasing difficulty
* Game-over detection
* Restart functionality

## Controls

| Key     | Action     |
| ------- | ---------- |
| `←`     | Move left  |
| `→`     | Move right |
| `Space` | Shoot      |
| `P`     | Pause      |
| `R`     | Restart    |

## How to Play

1. Control the spaceship at the bottom of the screen.
2. Move left and right to avoid enemy attacks.
3. Shoot the incoming enemies.
4. Destroy enemies to earn points.
5. Protect your spaceship and remaining lives.
6. The game ends when the player loses all lives or the enemies reach the player area.

```bash

```

### JavaScript

```bash
npm install
npm start
```
